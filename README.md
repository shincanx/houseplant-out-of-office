Entry for the [make.fun bounty "The Houseplant Out-of-Office"](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) — the funniest out-of-office auto-reply a houseplant would send, as a single line of at most 120 characters.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it to stdout. No network, no dependencies, deterministic.
